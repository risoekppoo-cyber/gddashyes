# Original Click Sounds default pack

Twenty unmodified WAV files extracted from `resources/clicksounds.default.packgen.zip`
in [clicksounds/geode-clicksound](https://github.com/clicksounds/geode-clicksound/tree/3b5389b37c6c1e0db90ed57099fd36910bbdd015), commit `3b5389b37c6c1e0db90ed57099fd36910bbdd015`.

Upstream pack ID: `clicksounds.default`; description credits “yesimapotato’s sayo pink switches” by yesimapotato. The upstream pack lists Click Sounds as its author. Upstream MIT license is retained in LICENSE; original byte hashes are in samples.json.

The browser adapter uses accepted game input events for Space, Up, W, mouse/touch and virtual keys. Inputs in settings do not trigger sounds. The first version plays on game controls in both levels and menus; it does not execute the native Geode package. Preferences are saved locally. Sounds start disabled; enable them in Mods → Click Sounds. Press and release selection, release toggle, volume and previews are provided.
