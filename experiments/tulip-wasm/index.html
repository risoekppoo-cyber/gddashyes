A compiled C++ mod hooked into the real game module

This experiment compiles upstream TulipHook, used by Geode, to WebAssembly. It dynamically loads a separate C++ test plugin and tests a real Geometry Dash getter.

This is a hook-engine experiment. The full Geode loader and existing .geode packages are not supported, and the full game is not booted by this test.

Downloads approximately 29 MB. Use Edge for comparison with your earlier test.
