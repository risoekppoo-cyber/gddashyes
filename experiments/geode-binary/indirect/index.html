Geode indirect binary translation test

A native Windows test DLL calls through the official Geode dispatch thunk, enters Geode's address getter, then calls back into the test DLL. Two separately translated WebAssembly modules share the guest CPU and memory.

All 16 general registers, five arithmetic flags and 256 stack bytes are checked against original machine instructions executed by Unicorn. This test does not initialize the full Geode loader or load existing mods.
