A source-ported Geode Hook SDK mod

This test compiles Geode’s upstream Hook.cpp and public Hook API with a small WebAssembly backend. A separate C++ mod uses Hook::create, enable and toggle against the real game module.

This is a limited SDK port. The complete Geode loader, Mod ownership, $modify classes and existing .geode packages are not supported.

Open the full-game menu-label experiment in Edge. It attempts to create a native Cocos label after menu initialization; that path still needs a browser boot and visual check.
